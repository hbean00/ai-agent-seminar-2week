# 학교 LMS (Canvas) — 예시

이 폴더(`capabilities.example/`)를 `capabilities/` 로 복사한 뒤 내용을 자신의
환경에 맞게 고쳐 쓰세요. 파일 이름이 곧 태그가 됩니다 — 이 파일은 `@lms`.

`capabilities/` 는 git-ignored 입니다. 기능 파일에는 보통 개인 PC의 절대경로와
운영 메모가 들어가기 때문입니다 (`projects.toml` 과 같은 이유).

---

수강 과목의 공지·게시글·강의자료에 접근한다.

실행 위치: `/path/to/your/lms-scripts`
(경로에 공백이 있으면 `cd` 할 때 따옴표로 감쌀 것)

| 하고 싶은 것 | 명령 |
|---|---|
| 최근 공지 조회 (가장 빠름, 로그인 불필요) | `python canvas_api.py` |
| 수강 과목 자료 일괄 다운로드 | `python lms_download.py --headless` |
| 특정 과목만 다운로드 | `python lms_download.py <과목ID> --headless` |
| Inbox 새 메시지 한 번 확인 | `python lms_notify.py --once` |

## 먼저 이것부터

**공지나 메시지 내용만 필요하면 `canvas_api.py` 를 쓴다.** API 토큰으로 바로
읽으므로 브라우저를 띄우지 않아 수 초 안에 끝난다.

브라우저 세션이 필요한 것은 반드시 `--headless` 를 붙인다. 붙이지 않으면
사용자 화면에 크롬 창이 뜬다.

## 주의

- 자격 증명은 그 폴더의 `.env` 에 있다. **그 파일 내용을 출력하거나 대화에
  옮겨 적지 말 것.**
- `lms_notify.py` 를 인자 없이 실행하면 **무한 루프로 계속 돈다.** 반드시
  `--once` 를 붙일 것.

---

## 기능 파일 쓰는 요령

- **무엇을 할 수 있는지**와 **어떤 명령으로 하는지**를 표로 적는다.
- 모델이 잘못 쓰기 쉬운 지점(무한 루프, 창이 뜨는 옵션, 느린 경로)을 명시한다.
- 비밀값은 적지 않는다. 파일 위치만 가리키고 "출력하지 말 것"이라고 쓴다.
- 한 파일이 4000자를 넘으면 잘리고 경고가 찍힌다. 길어지면 기능을 쪼갠다.
